В здании использовались нейросети Deepseek и Яндекс Алиса, примерное время работы 6 часов.

Лис в лесу 
Небольшая 2D-аркада на HTML5 Canvas: лис бегает по лесу, ловит мышей и пытается не проголодаться. Управление с клавиатуры, всё работает без сервера — в одном окне браузера.

Игровой процесс
Лис бегает по бесконечному лесу, камера следит за ним и прокручивает мир.
По лесу разбросаны мыши: чем больше съедено, тем быстрее уходит шкала сытости. Когда сытость падает до нуля — игра проиграна («Лис проголодался!»).
Съеденные мыши увеличивают счётчик 🐭, лучший результат сохраняется в localStorage и отображается как 🏆 Рекорд между сессиями.
Деревья — препятствия: через кроны не пройти, лис выталкивается из них по осям X и Y.

Управление
WASD или стрелки — движение
Space — прыжок
P — пауза (повторное нажатие продолжает игру)
R — мгновенный перезапуск

Интерфейс
Шапка с названием и описанием игры — над окном игры.
Кнопки «Пауза» и «Новая игра», шкала сытости и счётчики — над canvas.
Кнопка «Начать игру» — под окном игры, работает и как повторный запуск.
Экран проигрыша — полупрозрачное окно поверх поля с итоговым счётом.
При паузе над лисом появляется «Z-z-z».
Миникарта в углу показывает положение лиса и мышей на видимой области леса.

Технические детали
Отрисовка через Canvas 2D, весь мир рисуется относительно камеры — за кадр обрабатываются только видимые объекты.
Физика персонажа: разгон с трением, ограничение максимальной скорости, прыжок по параболе.
Коллизии: прямоугольники AABB для поедания мышей, выталкивание из деревьев.
Спрайты подгружаются из img/ (лис, дерево, мышь, фон).
Игровой цикл на requestAnimationFrame с фиксацией шага времени — скорость игры не зависит от частоты обновления монитора.

Обычный запуск (без установки)
Скачайте и распакуйте архив с проектом.
Откройте файл index.html двойным кликом — игра запустится в браузере по умолчанию.
Нажмите «Начать игру».
Подойдёт любой современный браузер: Chrome, Firefox, Edge, Safari. Сервер не нужен, интернет не нужен (кроме первой загрузки, если браузер кеширует спрайты).
